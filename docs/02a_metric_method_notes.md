# 第二步补充：按学习文档整理指标体系

状态：用户已授权后续步骤默认同意，原指标字典V0.1中的口径在本阶段沿用；CTR排行1000次的默认门槛为可调整展示规则。

参考《金融审批数仓（3数据仓库系统）》5.2.4节：原子指标描述业务过程、度量和聚合逻辑，派生指标进一步限定时间、维度及业务范围，衍生指标由相关统计结果计算比率等。

| 类别 | 本项目例子 | 实现意义 |
| --- | --- | --- |
| 原子指标 | 曝光次数SUM(impression_count)、点击次数SUM(click_count)、去重曝光用户COUNT(DISTINCT user_id) | 定义基础聚合逻辑，不能与某个页面临时定义混用 |
| 派生指标 | 2017-05-06某资源位按广告计划的曝光次数和点击次数 | 明确时间窗口、统计维度、筛选限定，支持DWS复用 |
| 衍生指标 | 对应范围CTR=点击/曝光、人均曝光=曝光/去重用户、分组曝光贡献率 | 在匹配范围分子分母上重算；不累计比率 |

质量指标单独记录，画像属性缺失按曝光加权和按源用户计数分开。现有10个业务指标和4类质量指标继续有效；学习文档的金融累积快照与省略DWS的特例不套用到广告。

示例只说明指标定义，不往业务数据中添加任何新记录。完整口径见02_metric_dictionary.md；后续按实际实现及检查结果修订，并保留差异记录。

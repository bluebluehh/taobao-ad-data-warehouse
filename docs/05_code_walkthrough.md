# 第五步附录：代码执行逻辑与核查方法

## 执行顺序

`python -m warehouse.build`从原始CSV建立样本ODS，再构建维度、曝光事实、公共汇总和ADS。`python -m warehouse.serve`启动只读查询服务；`python -m warehouse.export_preview`生成不用服务器即可打开的静态结果；`python -m warehouse.check`核对真实数据的边界、接口和重建一致性。

## build.py

1. `ROOT`由当前脚本位置推导项目根目录，`TZ`明确为UTC+08:00。参数`source`指定数据目录，`out`指定生成结果位置，`rate`是抽样概率，`seed`是固定种子。
2. `sources`递归定位三张CSV，检查每个名称只有一个实际文件，避免静默读取错误版本。`fingerprint`记录路径、字节数和修改时间；`program_hash`记录ETL、指标和SQL版本。复用前比较配置，不重新导入同一记录。完整SHA-256在首次扫描中计算；复用时的快速检查不重新计算源哈希，因此不抵御保留大小和修改时间的恶意篡改。
3. 默认在`warehouse.building.sqlite3`构建，旧库不动。`PRAGMA foreign_keys=ON`由schema启用，维度引用须有效；缓存上限约256MiB，临时计算允许落盘，不假设数据全放进内存。
4. `load_dimension`通过`csv.reader`读取维度源文件，检查表头顺序，识别末列名空格但保留原始表头清单。`executemany`每一万条批量插入ODS，比逐条提交更高效；维度源值作为文本保留，空白转换在DIM完成。
5. `load_exposure`边读取源字节边累计SHA-256。对每行用带种子的BLAKE2b计算64位稳定值，小于`rate*2^64`则选入样本。相同文件、种子、比例会选中相同行；并非随机截文件开头。完全相同内容的行抽样结果也相同，当前源核查无完全相同行。全量模式绕过抽样判断。
6. 当前曝光文件为无引号逗号的六列简单格式，采用逐行split并校验宽度；不是任意CSV的通用解析器。异常宽度写入reject；其他六列记录先入ODS，关键字段、时间、标签异常记原因。独立Python集合和Counter只累计有效样本的用户、广告、点击与日期，之后与SQL结果核对。
7. `make_dimensions`先检查源用户/广告键唯一且非空，再建代理键。画像没有匹配的曝光用户分别补建占位行，user_id各自保留，profile_matched=0。源属性NULL与未匹配成员含义不同。日期和24小时维度由日历规则计算。
8. `make_fact`把有效ODS关联到两个主维度，生成date_key、hour_key和两个计数事实。事实键保留源行号，外键约束防止悬挂引用。事实表不按用户时间戳去重；该组合不是唯一键。建立日期/资源位、用户、广告索引便于查询。
9. `make_summary`用相同聚合表达式生成DWS和默认ADS。每张表的UV只对自己的分组粒度有效；不同日期的UV不能直接相加。汇总CTR在ADS由计数重算。
10. `validate`以独立源样本计数、维度外键和各层总量做断言。失败则保留旧库和failed_run.json，不把失败结果当成功。成功后`os.replace`替换生成库，保存元数据、检查结果和ADS快照。

## metrics.py

- `AGG`集中定义曝光、点击、去重用户、点击用户和画像匹配等计数，防止不同页面各自定义。
- `ratio`遇到零分母返回None，导出JSON为null，页面显示“—”；有曝光零点击则返回0。
- `derive`从匹配范围内的计数计算CTR、用户点击比例、人均曝光及质量比率，不对已显示的小数反推。
- `scope`将查询筛选变成SQL条件，取值用占位参数绑定。质量范围跳过画像筛选，保留日期、广告等条件，因此不会将“已知性别”筛选后的100%覆盖误当作全体覆盖。
- `grouped`只允许白名单中的分组表达式；先形成全部筛选集合与总量，再分组、排序、门槛筛选和LIMIT。Top N贡献率仍除以完整分析范围总量。
- `bundle`只将本次查询的非画像范围暂存到连接临时表，复用它生成各面板，减少反复关联。主库用mode=ro打开；临时查询缓存可写不等于可以修改主库。结束后清理临时视图和表。

## serve.py与网页

`ThreadingHTTPServer`提供明确白名单的页面与API，不允许下载任意本地路径。主库只读；只在127.0.0.1监听。日期先后、排行维度、排序和门槛均验证，错误返回400。相同参数和数据库修改时间可复用小容量缓存；数据库重建后缓存自动失效。

网页通过FormData读取筛选项，调用API并更新所有面板。数据编码经HTML转义后展示；SVG图表由真实汇总结果绘制。图中曝光和CTR使用不同轴，跨日期UV由服务重新去重。CSV导出保存当前排行的原始数字比率，未知比率为空。静态版本将ADS快照嵌入HTML，禁止假装可筛选；保留导出功能。

## check.py

用实际样本核对日期筛选、跨日UV、画像未知组、零点击组、CTR门槛、SQL参数绑定、主库只读、非法HTTP参数和文件白名单。测试中的零点击组来自真实记录，不构造广告业务数据。两次全流程指标一致及源哈希一致，核实可复现性。另一次相同配置运行核实复用不重复插入。

当前不宣称已完成HTTP端到端和浏览器目视检查：本地请求受到执行环境套接字权限阻止，浏览器会话也连接失败。查询服务函数、JavaScript语法与页面视觉验收是不同的检查，状态分别记录。

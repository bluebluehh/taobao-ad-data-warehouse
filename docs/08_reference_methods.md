## 同数据集案例

厦大数据库实验室《基于Python和Spark的淘宝展示广告点击率预估》：https://dblab.xmu.edu.cn/blog/5589/ 。参考其源表理解、缺失问题及分析方向；不沿用前50万行作为代表性抽样、不将KNN填补画像当作原始观测属性、不按用户直接多对多关联曝光和购买进行广告归因。消费档次54.24%、城市等级32.49%的源表缺失率另由本地全量检查确认。

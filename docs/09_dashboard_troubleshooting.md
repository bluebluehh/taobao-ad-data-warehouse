# 本地看板连接故障记录

日期：2026年11月15日。

## 现象与检查

用户打开http://127.0.0.1:8765后出现ERR_CONNECTION_REFUSED。本轮检查未发现8765端口监听，项目服务代码、生成数据库和静态预览文件均存在。

尝试用隐藏后台进程启动，最初返回进程ID，但后续查询未发现该进程继续存活，日志也为空；因此不把这次尝试视为修复成功。随后通过持续执行会话重新启动，程序在HTTPServer绑定端口后输出Dashboard启动信息。浏览器是否已经连通尚未观测，不能把服务启动等同于页面验收。

## 推荐的持久运行方式

在项目文件夹双击scripts/start_dashboard.cmd。看到Dashboard地址后保持该命令窗口打开，再用本机正常浏览器访问http://127.0.0.1:8765。按Ctrl+C可停止，关闭命令窗口也会停止服务。

也可在项目根目录PowerShell执行：

```powershell
python -u -m warehouse.serve
```

这是常驻服务，需要保持运行。此前已生成的数据库无需重建。若显示端口已占用，可能已有一个服务正在运行，先尝试访问页面，不要反复创建进程或随意结束其他程序。

不运行服务也能打开output/midterm/dashboard_preview.html查看静态结果；该版本不执行筛选，不代表动态服务已经连通。

## 尚未证实的事项

本轮没有关闭防火墙、修改代理或扩大公网访问。未确认用户刷新后的浏览器结果；也未取得浏览器截图。后续由实际页面和HTTP响应确认端到端连接。
